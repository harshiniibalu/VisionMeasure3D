# VisionMeasure3D
This project mainly aims to develop a computer vision-based system for real-time object detection, depth estimation, and 3D dimensional measurement of real-word objects.  Using the Intel RealSense D455 RGB-D camera and YOLO-based object detection, the system identifies objects from live camera frames and extracts corresponding depth information to estimate their distance from the camera. By combining object detection, depth data, image processing, and camera geometry, the project focuses on estimating the real-world width, height, and spatial dimensions of detected objects. It also involves experimental analysis at different distances and positions to evaluate measurement accuracy by comparing estimated values with actual measurements. The project is implemented using Python, OpenCV, NumPy, Ultralytics YOLO, and the Intel RealSense SDK.
